### 🩸 [ Досье следователя / Ghoul Investigator Dossier ]

> *"Why do I have to save trash like you?"* — Kaneki Ken (The Black Reaper)

- **Кодовое имя:** Zirluka
- **Класс:** Backend / Fullstack Specialist
- **Основной профиль:** Архитектура высоконагруженных и масштабируемых REST API, построение строгих реляционных структур данных.
- **Текущая миссия:** Разработка сервиса **ZipLink** (аналитика трафика, роутинг ссылок, генерация QR-кодов).
- **Следующий рубеж силы:** Экспансия в **TypeScript** и глубинная оптимизация транзакций / индексов в **PostgreSQL**.
